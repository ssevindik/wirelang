# Netlist Import / Export

WireScript supports exporting schematics to industry-standard netlist formats and importing netlists back into the `WireScriptDb` representation.

---

## Supported Formats

| Format | ID | Extension | Description |
|---|---|---|---|
| SPICE | `'spice'` | `.net`, `.cir`, `.sp` | Standard SPICE netlist — compatible with LTspice, ngspice, KiCad, etc. |
| WireScript CSV | `'ws-csv'` | `.csv` | WireScript's own CSV netlist — easy to read, edit, and process |

---

## `exportNetlist(db, options?)` — DB → Netlist

Converts a `WireScriptDb` to a netlist string.

```ts
import { Circuit, DC, R, LED, GND, RED, compileDslToDb, exportNetlist } from '@ssevindikx/wirescript';

const circuit = Circuit('LED Driver', DC(5), R(330), LED(RED), GND());
const db = compileDslToDb(circuit);

// SPICE format (default)
const spice = exportNetlist(db);

// WireScript CSV format
const csv = exportNetlist(db, { format: 'ws-csv' });
```

### Options

```ts
interface NetlistExportOptions {
  format?:   'spice' | 'ws-csv';  // Output format (default: 'spice')
  title?:    string;               // Title comment in SPICE output (default: schematic name)
  spiceEnd?: boolean;              // Include .end directive (default: true, SPICE only)
}
```

### SPICE output example

```spice
* LED Driver
* Generated by WireScript db2netlist

V1 N1 0 5
R1 N1 N2 330
D1 N2 0 red

* Ground nets: 0

.end
```

### WireScript CSV output example

```csv
refdes,type,pin,net,value,model
V1,voltage_source,positive,N1,5,
V1,voltage_source,negative,0,5,
R1,resistor,1,N1,330,
R1,resistor,2,N2,330,
D1,led,anode,N2,0,red
D1,led,cathode,0,0,red
GND1,ground,gnd,0,,
```

## `importNetlist(src, options?)` — Netlist → DB

Parses a netlist string and returns a `WireScriptDb`.

```ts
import { importNetlist } from '@ssevindikx/wirescript';
import { promises as fs } from 'fs';

// From a SPICE file
const spiceSrc = await fs.readFile('circuit.net', 'utf-8');
const db = importNetlist(spiceSrc);

// From a CSV file
const csvSrc = await fs.readFile('circuit.csv', 'utf-8');
const db2 = importNetlist(csvSrc, { format: 'ws-csv' });
```

Format is **auto-detected** by default:
- First line matches `refdes,` → `ws-csv`
- Otherwise → `spice`

### Options

```ts
interface NetlistImportOptions {
  format?: 'spice' | 'ws-csv';  // Input format (default: auto-detected)
  name?:   string;               // Schematic name (default: parsed from SPICE title or 'imported')
}
```

## Aliases

All four alias pairs work identically:

```ts
import {
  exportNetlist, dbToNetlist, db2netlist,  // DB → netlist
  importNetlist, netlistToDb, netlist2db,  // netlist → DB
} from '@ssevindikx/wirescript';
```

## SPICE reference designator mapping

| WireScript type | SPICE prefix | Example |
|---|---|---|
| `resistor` | `R` | `R1` |
| `capacitor` | `C` | `C1` |
| `inductor` | `L` | `L1` |
| `diode`, `led` | `D` | `D1` |
| `voltage_source` | `V` | `V1` |
| `current_source` | `I` | `I1` |
| `npn`, `pnp` | `Q` | `Q1` |
| `nmos`, `pmos` | `M` | `M1` |
| `njfet`, `pjfet` | `J` | `J1` |
| `opamp`, `logic_gate` | `U` | `U1` |
| `power_rail` | `V` | `VCC1` |
| `ground` | — | net `0` |

### Terminal order

SPICE reads terminals in its own order, which is not WireScript's declaration
order. Export reorders them; import names them back.

| Element | SPICE order | WireScript pins |
|---|---|---|
| `Q` | collector, base, emitter | `C`, `B`, `E` |
| `M`, `J` | drain, gate, source | `D`, `G`, `S` |
| `V`, `I` | +, − | `positive`, `negative` |
| `D` | anode, cathode | `anode`, `cathode` |

> **Fixed in 0.5.0.** Transistors were previously emitted in declaration order
> (`B, C, E`), which SPICE reads as collector, base, emitter — so every
> exported netlist had collector and base swapped.

### What SPICE cannot express, and how it survives anyway

SPICE has no symbol for a ground reference, a power rail, or an LED as distinct
from a diode. WireScript writes annotation comments that simulators ignore, so
nothing is lost on the way back:

```
V1 node_1 0 5
R1 node_1 node_2 330
D_LED1 node_2 0 1.8

* Ground nets: 0
* Power rails: VCC1=VCC@node_1
* Devices: V1=voltage_source, R1=resistor, D_LED1=led
```

- **`* Ground nets:`** — which net is the 0V reference, re-materialised as a
  `GND()` component on import.
- **`* Power rails:`** — which `V` elements were really `VCC()`/`VDD()` rails.
- **`* Devices:`** — each element's exact WireScript type, so an LED comes back
  an LED and a PNP comes back a PNP.

**AC sources** are written as `SIN(0 <amplitude> <frequency>)` rather than a
bare number, which is both correct SPICE and what keeps an AC source from
returning as DC.

> **Power rails were dropped entirely before 0.5.0**, so an exported netlist
> had no supply in it and simulated as a dead circuit.

### SI value suffixes (import)

| Suffix | Multiplier | Example |
|---|---|---|
| `T` | × 10¹² | `1T` = 1 TΩ |
| `G` | × 10⁹ | `1G` = 1 GHz |
| `MEG` | × 10⁶ | `2.2MEG` = 2.2 MΩ |
| `K` | × 10³ | `10K` = 10 kΩ |
| `M` | × 10⁻³ | `100M` = 100 mA |
| `U` | × 10⁻⁶ | `47U` = 47 µF |
| `N` | × 10⁻⁹ | `10N` = 10 nH |
| `P` | × 10⁻¹² | `100P` = 100 pF |
| `F` | × 10⁻¹⁵ | |

> **Note**: `G` is checked after `MEG` to ensure `2.2MEG` is not misread as `2.2M + 'EG'`.

## Round-trip example

```ts
import {
  Circuit, DC, R, C, GND,
  compileDslToDb,
  exportNetlist,
  importNetlist,
  reverseDbToDsl,
} from '@ssevindikx/wirescript';

// 1. Build a circuit
const original = Circuit('RC Filter', DC(5), R(1000), C(1e-6), GND());

// 2. Serialize to DB
const db = compileDslToDb(original);

// 3. Export to SPICE netlist
const spice = exportNetlist(db);
console.log(spice);
// * RC Filter
// V1 N1 0 5
// R1 N1 N2 1000
// C1 N2 0 1e-6
// .end

// 4. Import back
const rebuilt = importNetlist(spice);
console.log(rebuilt.components.length); // 3 (V, R, C)

// 5. Convert rebuilt DB back to DSL
const dsl = reverseDbToDsl(rebuilt);
console.log(dsl);
```

## CLI usage

See [CLI Reference](./cli.md) for `to-netlist` and `from-netlist` commands.

```sh
# DB JSON → SPICE
wirescript to-netlist circuit.json

# DSL/TS → SPICE (direct, no intermediate JSON needed)
wirescript to-netlist circuit.ts --format spice --out circuit.net

# DB JSON → WireScript CSV
wirescript to-netlist circuit.json --format ws-csv --out circuit.csv

# SPICE → DB JSON
wirescript from-netlist circuit.net --out circuit.json

# CSV → DB JSON
wirescript from-netlist circuit.csv --format ws-csv --out circuit.json
```
